# Release v5.9.1 — Modulares Datei- und Bild-Upload-System für den KI-Chat

### Übersicht

5.9.1 überarbeitet die KI-Anhänge grundlegend. Text, Code, Dokumente und Bilder werden jetzt in einer modularen Architektur verarbeitet, die sich naht an OpenAI-kompatible und Anthropic-APIs anpasst. Die Desktop-Intent-Erkennung verhindert, dass Bilder versehentlich an den Rechner übergeben werden, und das Frontend unterstützt Multi-File-Upload mit Paste, Drag-Drop und Thumbnail-Vorschau.

---

### Was wurde behoben & verbessert?

#### 1. Architektur: Processor und Provider

* **Modulare Struktur:** Die Anhangsverarbeitung liegt jetzt in zwei klaren Modulen. `ai_attachment_processor` klassifiziert Dateien inhaltlich (Text, Bild, Dokument, Binär), `ai_attachment_provider` übersetzt sie in die Blockform des Anbieterprotokolls (OpenAI oder Anthropic).
* **Provider-agnostisch:** Neue Anbieter-Einträge im Admin-Panel funktionieren ohne Code-Änderung, solange sie `protokoll_chat="chat_completions"`, `"responses"` oder `"anthropic_messages"` verwenden.
* **Dokumentiertes Fallback:** Unbekannte Protokolle fallen auf OpenAI-Format zurück — das ist das verbreitete Format und funktioniert für alle OpenAI-kompatiblen APIs.

#### 2. Text- und Bildregeln

* **Alle Textformate erlaubt:** Markdown, JSON, Code, Logs, `.env`, SVG, PHP, Batch und Shell sind Text, keine Executables. Der Server führt sie nie aus, er liest sie. Eine Endung oder ein `<?php` am Dateianfang ist kein Sicherheitsrisiko, sondern Inhalt.
* **Bildgrößen erhöht:** 12.000 px Kante und 50 MP Pixelzahl statt 4.096 px / 16 MP. Moderne Kamerafotos werden angenommen und beim Modell auf das Kontextbudget verkleinert.
* **Text-Budget skaliert:** Das Budget für Anhänge wächst mit dem Kontextfenster (4k-160k Zeichen). Ein 200k-Fenster sieht jetzt den Anfang einer großen Logdatei, statt nur die ersten 24k Zeichen.
* **SVG als Text:** SVG wird als XML extrahiert, nicht als Bild an das Modell geschickt. Das verhindert Konvertierungen und erhält den Code.

#### 3. Desktop-Intent-Erkennung

* **Robusterer Schutz:** Alle Desktop-Tools (`desktop_system`, `desktop_steuern`, `desktop_launch_app`) werden bei Anhang-Turns ausgeblendet, außer der Benutzer nennt ausdrücklich den Rechner, ein Programm oder eine Eingabe.
* **Eingefrorene Absicht:** `zustand["desktop_absicht"]` speichert die Intent-Antwort der ursprünglichen Frage, nicht die letzte Provider-Nachricht (die oft ein Gedächtnis- oder Anhangsblock ist).
* **Defense-in-Depth:** Zwei unabhängige Schranken — das Werkzeugangebot oben und eine zusätzliche Prüfung in `_desktop_behandeln` — verhindern, dass ein Bild "an den Rechner übergeben" wird.

#### 4. Frontend: Multi-File und Paste

* **Mehrere Dateien gleichzeitig:** Der Dateidialog akzeptiert mehrere Dateien. Drag-Drop und Paste (Strg+V) funktionieren ebenfalls.
* **Thumbnail-Vorschau:** Bilder zeigen eine Vorschau der ausgewählten Datei, Text und Dokumente ihr Icon. Entfernt wird einzeln per X vor dem Absenden.
* **Timeout-Mechanismus:** Hängende Uploads werden nach 60s abgebrochen. Der Zustand wird zurückgesetzt, die UI bleibt responsive.
* **Leerer Text mit Anhang:** Ein Bild ohne Begleittext ist eine vollständige Frage ("Was ist das?"). Die Sperre `!content` wurde aufgehoben, wenn mindestens ein Anhang vorhanden ist.

#### 5. Sicherheit und Validierung

* **Magic-Byte-Erkennung:** ELF-/PE-Signaturen bleiben Binaerdateien, auch wenn die ersten Bytes zufällig als UTF-8 lesbar wären. Nur eine Textendung darf sie retten — dann ist es Text, der zufällig mit "MZ" beginnt.
* **Archive gesperrt:** ZIP-basierte Office-Dateien werden extrahiert, andere Archive (ZIP, 7z, RAR, tar) bleiben gesperrt.
* **Redaction bleibt:** Textanhänge werden weiterhin auf Geheimnisse geprüft und redigiert, bevor sie an den Anbieter gehen.

#### 6. Technik und Prüfung

* **Neue Module:** `ai_attachment_processor.py`, `ai_attachment_provider.py`, `aiAnhangTypen.ts`, `useAnhangUpload.ts`, `AiAnhangLeiste.tsx`, `AiAnhangListe.tsx`.
* **Geprüft:** Backend-Tests decken Text-/Bildregeln, Desktop-Intent, Provider-Adapter und Timeout ab. Frontend-Suite prüft Multi-File, Paste, Vorschau und leeren Text mit Anhang. Alle Tests liefen durch.

---

### Was du tun musst

* Auf Version 5.9.1 aktualisieren über das Web-Panel (**Einstellungen → System → Update**) oder auf dem Server via `sudo ./scripts/update.sh`. Vorher wie gewohnt ein Backup anlegen.
* Keine weiteren Schritte nötig. Die Architektur ist abwärtskompatibel; bestehende Konversationen und Anhänge funktionieren unverändert.
