# Hotfix v5.8.3 — Pontis öffnet Weiterleitungslinks auf Android ohne Hänger

### Übersicht

Dieser Hotfix behebt, dass Maunting Pontis unter Android einfror, wenn ein Link oder eine Weiterleitung auf eine andere App zeigte – etwa beim Login über die Shop-App. Die App reagierte nicht mehr, Android meldete „Pontis reagiert nicht“ und beendete sie. Pontis übergibt solche Adressen jetzt, ohne den UI-Faden zu blockieren.

---

### Was wurde behoben & verbessert?

#### 1. Fremdprotokolle blockierten den UI-Faden

* **Ursache:** Zeigt ein Link auf ein Fremdprotokoll (`mailto:`, `tel:`, `market://`, eine App wie WhatsApp, Instagram oder die Shop-App), fragt der Tab die Rust-Seite, wohin die Navigation geht. Diese öffnete die andere App über die Tauri-Plugin-Brücke und wartete dabei auf eine Antwort aus dem UI-Faden – in dem der Aufruf selbst lief. Der Faden wartete damit auf sich selbst. Nach fünf Sekunden brach Android den Eingabeversuch ab (ANR, „Input dispatching timed out“).
* **Behoben:** Unter Android läuft das Öffnen der Fremdadresse jetzt in einem Hintergrund-Faden. Der UI-Faden kehrt sofort zurück, die Navigation im Tab wird abgebrochen, und die andere App öffnet sich kurz danach.
* **Gilt für alle Fremdprotokolle:** Nicht nur der gemeldete Shopify-Login, sondern auch andere OAuth-Rücksprünge, App-Links sowie `mailto:`- und `tel:`-Links. Welche Adressen ein Tab öffnen darf, bleibt unverändert: Gefährliche Schemata wie `intent:`, `file:` oder `javascript:` gehen weiterhin nie ans System.
* **Geprüft:** Ein Instrumentation-Test ruft die Navigation im UI-Faden auf und verlangt, dass sie bei einem Fremdprotokoll sofort zurückkehrt. Vor dem Fix blieb er dort hängen; auf dem Emulator läuft er jetzt durch. Die Host-Tests für erlaubte und gesperrte Schemata bleiben grün.

Wir hoffen, dass die Hänger beim Öffnen von Weiterleitungslinks damit behoben sind. Tritt weiterhin einer auf, hilft uns ein neuer Fehlerbericht aus den Android-Entwickleroptionen, damit wir den Stack erneut prüfen können.

---

### Was du tun musst

* Auf Version 5.8.3 aktualisieren über das Web-Panel (**Einstellungen → System → Update**) oder auf dem Server via `sudo ./scripts/update.sh`. Vorher wie gewohnt ein Backup anlegen.
* Die Desktop-Apps und Maunting Pontis anschließend über **Einstellungen → Über → Update prüfen** aktualisieren.
* Auf Android danach den Weiterleitungslink bzw. den Login erneut testen.
