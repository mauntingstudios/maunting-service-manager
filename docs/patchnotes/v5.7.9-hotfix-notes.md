# Hotfix v5.7.9 — Fokus auf datenschutzfreundliche Websuche (SearXNG & Brave)

### Übersicht

Dieser Hotfix bereinigt die integrierte Websuche in Maunting Server Manager und Maunting Pontis: Die veraltete Google Programmable Search Engine (Custom Search JSON API) wurde vollständig aus dem Backend und der Benutzeroberfläche entfernt. Maunting Search und Singra KI setzen ab sofort konsequent auf das lokale SearXNG-Sidecar und die offizielle Brave Search API.

---

### Was wurde geändert & verbessert?

#### 1. Google Programmable Search (CSE JSON API) restlos entfernt
* **Hintergrund:** Google hat die Custom Search JSON API für Neukunden geschlossen und das endgültige Support-Ende für den 1. Januar 2027 angekündigt. Durch die Entfernung wird verhindert, dass tote Schnittstellen oder veraltete API-Felder im System verbleiben.
* **Schlankere Codebasis:** Sämtliche backendseitigen Aufrufroutinen, Verschlüsselungsmechanismen für Google-Schlüssel und zugehörige API-Endpunkte wurden gelöscht.
* **Aufgeräumte Einstellungen:** Im Reiter *Suchmaschine* entfallen die Eingabefelder für Google-API-Schlüssel und Suchmaschinen-ID (cx).

#### 2. Einheitliches Sucherlebnis mit SearXNG und Brave Search
* **Zwei starke Säulen:** Maunting Search stützt sich weiterhin auf das private, lokale SearXNG-Sidecar sowie optional auf die datenschutzfreundliche Brave Search API mit eigenem Webindex.
* **KI-Integration intakt:** Singra KI nutzt dieselbe Suchschicht wie der Browser Maunting Pontis und bereitet gefundene Webseiten weiterhin automatisch für Recherchefragen auf.

---

### Was du tun musst

* Auf Version 5.7.9 aktualisieren über das Web-Panel (**Einstellungen → System → Update**) oder auf dem Server via `sudo ./scripts/update.sh`.
* Die Desktop-Apps und der Pontis Browser können anschließend direkt über **Einstellungen → Über → Update prüfen** aktualisiert werden.
